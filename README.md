# 🇮🇳 LPU-NCC Website

Official website developed for the **National Cadet Corps (NCC), Lovely Professional University**. Built using the **MERN Stack** with a focus on responsiveness, security, and interactive user experience.

## 🔗 Live Project

🌐 [View Website](https://lpunccwebsite.z29.web.core.windows.net/)

---
 
## 🚀 Tech Stack

- **Frontend**: HTML, CSS, JavaScript, React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **Deployment**: Render
- **Version Control**: Git & GitHub

---

## 🎯 Features

- 🔐 Secure registration form with form validation and DB integration
- 🖼️ Dynamic photo slider and media section
- 📢 “What’s New” animated updates section
- 📱 Fully responsive for mobile, tablet, and desktop
- 📄 Informational pages with dropdown navigation (e.g., NCC Motto, Aim, Flag, Rank)
- ⚙️ Backend APIs for form submissions and dynamic content handling
- 🌐 Hosted online and actively used by LPU-NCC
